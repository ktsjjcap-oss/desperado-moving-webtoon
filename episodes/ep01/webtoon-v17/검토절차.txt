# DESPERADO 제작 후 검토 절차

사용자 지시(2026-10-16): 완성 뒤 실제 컷을 다시 검토하고, 문제 구간을 수정한 뒤 수정본까지 재검토한다. 이 절차를 다음 제작에도 적용한다.

1. 대본 검토와 실제 이미지 검토를 별개로 기록한다. 프롬프트의 의도를 그림의 성립 근거로 쓰지 않는다.
2. 각 컷의 인물 위치, 시선, 엄폐물의 실제 높이·폭, 접지·손 접점, 짐의 하중, 경비 위치와 이동 경로를 확인한다.
3. 은신 컷에는 경비 쪽 시점과 인물 쪽 시점을 함께 확인한다. 독자에게 보인다는 이유만으로 들킨다고 단정하지도 않고, 카메라 밖이라는 이유로 가려졌다고 판단하지도 않는다. 물리적 가림이 필요하다.
4. 추격에서는 앞뒤 거리와 소요 행동을 대조한다. 경비가 기다려줘야만 가능한 대화·상차·정지 구간은 반려한다.
5. 전체를 순서대로 읽고 정보 선행 제시, 대사 순서, 소품·의상·출입구 연속성 및 결말을 재확인한다.
6. 불합격은 이유와 해당 이미지 파일을 기록하고 재작업한다. 수정 이미지의 실제 픽셀과 앞뒤 컷을 다시 본 뒤 판정한다.
7. 웹 화면·이미지 로딩 검사는 서사 검수와 분리한다. 기술 검사를 통과한 것으로 이야기까지 통과했다고 쓰지 않는다.
8. 공개 결과에는 실제 수행 범위와 남은 한계를 표시한다. 자체 편집 판단을 실제 독자 조사·흥행 보장·완벽함으로 표현하지 않는다.
