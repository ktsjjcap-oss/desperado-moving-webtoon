공구를 쓰는 손에서 바로 문손잡이를 잡는 결과로 넘어가지 않고, 공구를 수납하는 연결 동작을 넣었습니다. 현장 대사, 무전, 화면 밖 발소리를 별도 편집층에 두고, 발소리 뒤 여백은 위협이 아직 보이지 않는 시간을 담당하게 했습니다. 반복 인덱스에 따라 여백을 넣는 CSS는 사용하지 않았습니다.

세로 웹툰 3작품과 현대 액션 만화 1작품의 실제 화면 비교

김부장

실제로 본 범위
1화 도입, 호명→남성 얼굴→질책 대사→세로로 긴 인물 배치 공개. 회차 전체나 전투 구간을 읽은 것으로 계산하지 않음.
화면에서 확인한 것
대사와 얼굴을 먼저 제시하고, 다음 긴 컷에서 뒤쪽 사람들과 무릎 꿇은 인물을 차례로 공개한다. 한 컷을 스크롤하면서 관계 정보가 추가된다.
DESPERADO에 적용
위험을 설명한 뒤 바로 경비 전신을 보여주지 않는다. 청각 반응→화면 밖 발소리→동작 중단으로 독자가 먼저 위험을 기다리게 한다.
차용하지 않는 것
길게 늘리는 것 자체가 목표가 아니다. 불필요한 무릎 꿇기나 상황은 차용하지 않는다.

싸움독학

실제로 본 범위
1화 시작 댓글→인사→교실과 셀카봉이 한 세로 구도로 공개되는 구간. 도입부 표본만 직접 관찰.
화면에서 확인한 것
방송 댓글을 먼저 보여주고, 인사하는 인물에서 손과 셀카봉으로 내려가며 방송 시점의 근거를 그림 안에 넣는다. 설명과 소품이 별개가 아니다.
DESPERADO에 적용
CCTV 화면을 넣는다면 렌즈 방향→동일 문과 인물의 모니터상 위치를 맞춘다. 시청자가 보고 있는 화면과 현장 시점을 구별한다.
차용하지 않는 것
댓글 UI를 우리 장면에 장식처럼 복제하지 않는다. 현재 콘티는 모니터 증명까지 없으므로 카메라 사각 검증 통과로 판정하지 않는다.

입학용병

실제로 본 범위
1화 도입 여성 클로즈업→생각→외부 호명→교실 문으로 들어오는 인물과 착석 인물이 함께 보이는 전경→소문 대사. 액션 분석으로 부풀리지 않음.
화면에서 확인한 것
화자 등장 전에 대사가 먼저 걸리고, 전경에서 문턱·이동자·듣는 사람을 동시에 확인한 뒤 대화로 좁힌다. 위치 설명을 건물 이름표로 대신하지 않는다.
DESPERADO에 적용
통신 음성과 현장 속삭임을 구분한다. 새 장소로 넘어갈 때 문턱을 지나는 컷 또는 진입 방향이 있는 전경을 둔다.
차용하지 않는 것
교실 장면을 잠입 성공의 참고 사례로 취급하지 않는다. 차용 대상은 공간 소개와 화자 순서뿐이다.

더 페이블

실제로 본 범위
공식 1화 인쇄면 3~11쪽 직접 관찰. 4~5쪽 펼침은 화면 위쪽 일부가 잘렸으며 전 페이지 정독으로 계산하지 않음.
화면에서 확인한 것
3쪽은 부품과 손의 세부 동작을 여러 컷으로 나누고, 6쪽은 도구와 손을 연결한다. 7~11쪽은 문손잡이→문틈→복도 상대→충돌→바닥에 놓인 무기와 남은 사람→빈 복도를 분리해 결과를 보여준다.
DESPERADO에 적용
장갑도 진품의 원위치→접근하는 손→교체 동작→진품이 들어간 보관처→남은 복제품→확인자의 반응을 구별한다. 복도 테스트에서는 공구가 갑자기 사라지는 대신 수납 컷을 추가했다.
차용하지 않는 것
총기 사용이나 살해 동작을 우리 작품에 대입하지 않는다. 인쇄 우→좌 배열을 그대로 세로에 붙이지 않는다.

장갑 구간에 필요한 최소 독해 설계

다음은 원작을 대체하는 새 사건이 아니라, 원작의 탈취/교체 사건을 그림으로 설명할 때 빠뜨릴 수 없는 정보 목록입니다. 구체적인 탈취 방법과 결말은 원작 확인 후 채웁니다.

독자가 확인해야 하는 정보보여줄 그림반려 조건
목표와 접근 장애보관처 전경, 진품의 동일 특징, 감시자와 접근 동선고가 장갑이 이유 없이 일반 탁자 위에 놓임
선택의 근거브리핑에서 본 장치/규칙이 현장에서 일치하는 장면해결 순간 새 능력이나 보안 예외 등장
실제 물건 변화진품의 원위치→손의 접촉→옮겨진 보관처→남은 물건을 구별손이 가린 동안 교체했다고 대사로 선언
예상 밖 위기이미 공개한 규칙에 따라 생기는 새 위험교체 때 조용했던 판별기가 나중에 이유 없이 울림
팀원의 대처문제 인지→선택→행동→남은 시간과 위치의 변화덩치만 크고 기여 없음 / 경비가 대화를 기다림
탈출과 원작의 후속 사건직전 전경에 있던 출구·연결부를 실제로 통과옥상→주차장 순간이동 / 원작에 없던 구출 의뢰 결말

콘티 검수 결과와 재작업 기록

1차 반려: 손 접사 반복, 공구가 사라짐, 렌즈 방향을 알 수 없는 돔 CCTV, 요구했던 복도 교차부 미표현.

2차 수정 후 반려: 공구 수납 연결은 생겼으나 전경에 카메라가 두 개가 됨. 배경의 닫힌 문은 여전히 교차부를 입증하지 못함.

3차 재검수: 전경의 중복 카메라는 하나로 수정됨. 공구 사용→수납→빈손으로 손잡이 대기라는 순서는 확인 가능. 그러나 카메라 근접 컷만으로 사각 범위를 증명할 수 없고, 원거리 배경은 여전히 닫힌 문이다. 따라서 전체 잠입 장면 통과 아님 / 컬러 제작 보류. 현재 시험은 발소리 때문에 문 열기를 중단하는 시점까지만이다. 은신과 경비 통과가 성공했다고 주장하지 않는다.

옷 주름·배경 질감이 콘티치고 여전히 많다. 최종 화풍 통과도 아니다. 완성판에서는 머리 덩어리, 그림자 면, 중요한 접점 외의 선을 더 정리해야 한다.

강의의 실제 적용

Clip Studio 공식 세로 웹툰 제작 글의 대사·여백·긴 원고 설계를 대조했다. 파일 분할 규격과 실제 연출 컷의 높이를 구별한다. 현재는 고정 규격으로 전편을 재생성하지 않는다.

원작 확인 상태

로컬 원작 후보와 과거 채팅 ‘무빙툰 재제작 준비’, ‘배포 완료 보고’, ‘기획 복습 정리’를 추가 확인했다. 사용자 원작 본문은 찾지 못했다. 과거 AI 각색본은 남아 있으나 원작으로 취급하지 않는다. 원작 파일명 또는 채팅 제목 확인을 요청한 상태다. 가수 의뢰인·매니저 선행 절도·협박 결말은 계승하지 않는다.

이 자료의 목적은 기준을 새로 선언하는 것이 아니라, 실제 결과에서 실패를 찾아 기록하고 다음 제작을 막는 데 있다. 공구 연결과 중복 CCTV는 수정했지만 남은 공간 문제를 해결하기 전에는 다음 장면과 컬러를 통과시키지 않는다.
