# EP01 v6 복구 및 제작 기록

2026-10-13. 이전 GitHub 저장소의 v5 원본·이미지·재생 코드를 복구했다. 중단된 작업 기록의 승인 시나리오에서 앞 108컷을 복구하고, 잘린 마지막 4컷은 케이스 확인과 치킨 대사의 연결로 복원했다. 이전 원격 v6 PNG는 현재 호스트에 없어 복구한 콘티와 v5 인물 기준으로 다시 제작했다.

## 결과

- 시퀀스 1 계획·진입 40컷, 시퀀스 2 검수실 교환 36컷, 시퀀스 3 탈출·재합류 36컷. 총 112컷, 원화 28개.
- 나레이션·무전·효과음 표기를 포함한 228개 음향 구간. 인물별 음성을 편집하고 출입문·경보·추격 효과음을 혼합했다. 별도 긴 BGM을 재생한다. 전체 시간축 719.003초.
- 전체 컷 카메라 움직임과 실제 야경·공연·케이스 교환 영상 3개. 모든 컷이 인물 전체 동작 영상으로 생성된 형태는 아니다.
- 아래 스크롤 진행, 위 스크롤 되감기·음성 정지, 다시 내려갈 때 해당 지점 재생, 자동 재생, 위치 슬라이더, 음소거, 대사 읽기.
- 원본 PNG는 보존하고 웹용 WebP 28개를 별도 인코딩했다. 원화 요청은 built-in image_gen, 영상·음향은 Runway를 사용했다.

## 이야기·작화 수정

밴 준비와 이동 대화를 늘리고 직원 동행 규정을 보여준다. 후문은 안쪽 푸시바로 열고 두 남자는 밖에서 대기한다. 직원에게 젓가락을 정상적으로 전달한다. 1층에서 B1·B2로 내려가고 발각 뒤에만 올라간다. 잠긴 금고의 열린 천장이나 무게 감지 장치는 사용하지 않는다. 검수실의 닫힌 케이스를 교환하며, 담당자의 시선과 운송 기사의 조기 도착이 실패 원인이다.

무전 인물이 같은 장소에 등장한 컷을 수정했다. 검수 담당자는 흰 셔츠·검은 번 헤어·직사각형 안경의 여성으로 맞췄다. 준비 장소의 진품 노출, 교환 뒤 열린 케이스, 원타치 개인 장갑의 보석 표시를 제거했다. 시설 지원 조끼는 잠입 중 유지하고, 1층 출구가 막힌 뒤 계단참에 버린다. 이후 원래 재킷으로 탈출한다. 장갑은 마지막 밴 확인 때에만 다시 드러난다. 옥상에는 고정 와이어·하네스·난간·결손 격자판을 보여준다. 4시퀀스 고해성사 반전, 의뢰인·배후·보수의 미공개 설정은 유지한다.

음성 서비스가 실패한 두 문장은 의미를 유지해 수정했다. 최종 시나리오·원화·음성에 같은 수정 문장을 반영했다. 영상의 잘못 생성된 문구는 편집으로 제거했고, 대사가 없는 공연·교환 컷을 영상화했다.

## 검증

112개 원화 표시, 719초 음성, 3개 영상 로딩, 가로 넘침 없음, 시작·자동 재생·되감기 시 음성 정지·재진행을 실제 브라우저에서 확인했다. 390px 모바일 폭을 확인했다. MP3·MP4의 Range/HEAD/오류 응답 9개 검사와 JavaScript 문법 검사를 통과했다. 영상의 첫 프레임·중간 프레임을 검토했다.
