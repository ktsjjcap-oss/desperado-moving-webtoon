# DESPERADO · 원본 개작 v4 자체 편집 검수

검수 범위: EP01 시퀀스 1, 8개 스트립·32컷. 이번 결과는 정지 원본이다. 무빙·음성·효과음은 적용하지 않았다.

## v3 독자 검수에서 지적한 문제와 개작 결과

| 문제 | 실제 개작 |
|---|---|
| 배경 소개와 설명부터 시작 | 직원 출입구에서 배달이 막히는 현재 사건으로 시작하고, 작은 문제를 해결할 인물이 누구인지 먼저 보여 준다. |
| 계획대로만 진행되어 긴장 없음 | 직원 동행이라는 새 진입 조건과, 후문 앞에서 고객에게 다시 불리는 두 단계 장애를 넣었다. |
| 팀원 이름·관계가 남지 않음 | 대화 속에서 딱지·락스·찬호·원타치의 이름을 사용한다. 고객을 우선하는 딱지, 원칙을 정하는 락스, 장난을 치는 찬호, 준비하고 조용히 돕는 원타치를 행동으로 구별한다. |
| 농담만 따로 끼운 느낌 | 치킨에 손대는 찬호, 문을 부수지 말라는 오해, 실제로 필요한 젓가락을 통해 상황과 행동에서 유머가 이어지게 했다. |
| 같은 앉은 자세·거리 반복 | 조끼를 입는 동작, 준비 소품, 반응 클로즈업, 통로 전경, 손·발·문턱 동작, 내려다보는 계단을 분리했다. |
| 동료가 문 앞에서 뒤로 이동 | 후문을 여는 컷에는 동료를 등장시키지 않고, 골목 접근 → 문 바로 밖 대기 → 문틈 전달 → 직원 복귀 → 문턱 통과 순서로 고정했다. |
| 마지막이 다음 단계 안내뿐 | 빈 운반 케이스를 준비한 반출팀의 이른 도착을 보여 주며 임무 시간에 새 변수를 만든다. |

## 실제 원화에서 확인·수정한 항목

- 장갑의 감정가 100억, 핑크 다이아, 공연 후 금고 복귀, 반출까지 4분을 구분했다. 100억을 팀 보수로 설명하지 않는다.
- 가수를 찬호와 다른 밝은 머리·무대 의상으로 그렸다. 락스의 화면 밖 대사를 가수의 대사로 오인하지 않도록 꼬리와 화자 표기를 확인했다.
- 출입 규정은 직원 동행으로 해결한다. 직원의 출입증을 딱지의 출입증처럼 만들지 않았고, 경비는 규정을 지킨다.
- 준비한 젓가락의 포장과 주머니, 꺼내는 동작, 문틈 전달, 직원에게 주는 결과를 확인했다.
- 치킨을 전달한 뒤 봉투가 다시 가득 찬 모습으로 나타난 오류를 수정했다. 빈 봉투는 접어서 조끼 주머니에 넣는다.
- 봉투의 상호가 달라진 부분을 ‘행복한 치킨’으로 통일했다. 주문 영수증 ‘운영팀’은 유지했다.
- 찬호가 양손을 허공에 드는 애매한 구도를 한 손을 치킨 쪽으로 뻗는 동작으로 수정했다. 팔을 가볍게 제지하는 목적이 보이도록 했다.
- 후문 안쪽의 푸시바와 바깥 손잡이를 구별했다. 저각도에서 허리 높이 푸시바를 발목 높이에 그리지 않았다.
- 지하 2층 하행 계단은 위에서 내려다보는 구도로 확인했다.
- 반출팀의 케이스는 비어 있다. 장갑이 앙코르 전에 반출된 것으로 설정하지 않는다.
- 반출팀 도착을 알리는 무전의 화자 오타를 ‘찬호’로 수정했다.

## 편집과 검증

원화 파일을 재편집·합성하지 않고, 원본 내 컷 경계를 뷰어에서 구분해 32컷으로 읽힌다. 컷 여백은 준비, 빠른 동작, 새 변수의 발견에 따라 달리 설정했다. 한글과 말풍선은 실제 원화에 포함되어 있으며 중간 설명 슬라이드는 없다.

그림을 생성했다는 사실과 재미 검수는 별개다. 자체 검수 판단은 ‘v3의 순조로운 진입 설명에서, 작은 장애를 협업으로 해결하는 장면으로 개선되었다’이다. 전체 EP01 연재본이나 순위 경쟁력을 입증한 평가가 아니다. 외부 독자 테스트는 수행하지 않았다.

독자 관점에 남는 과제: 이 시퀀스는 딱지의 진입 역할이 중심이다. 찬호의 핵심 능력과 개인 서사는 이후 시퀀스에서 실제 사건으로 보여 주어야 한다. 첫 시퀀스가 장갑 탈취 전체를 해결했다고 오인시키지 않는다. 금고 앞의 큰 장면은 후속 시퀀스의 과제다.

## 배포 페이지 확인

- 공개 페이지를 실제 클라우드 브라우저에서 열었다.
- 기본 760px와 모바일 미리보기 390px에서 32컷 모두 이미지가 로드되고, 가로 넘침과 잘못된 컷 경계가 없음을 확인했다.
- 21~27컷의 직원 호출·젓가락 전달·진입과 30~32컷의 하행 계단·빈 운반 케이스·새 변수를 실제 화면으로 읽었다.
- 마지막 컷과 페이지 끝까지 스크롤되는 것을 확인했다.
- 공개 HTML은 배포할 원본과 일치한다. 기존 무빙 플레이어 기능은 이번 변경 범위에 포함하지 않았다.
