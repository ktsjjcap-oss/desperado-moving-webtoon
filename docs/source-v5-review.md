# 원본 개작 v5 검수 기록

## 독자 이해를 위해 바꾼 점

- 다섯 명을 앞에서 소개하고 실제 배달·검색대 지연·차량 지연·금고 탈취 역할로 연결했다.
- 문받침은 열린 후문 아래에 넣었다가 합류 뒤 회수한다. 젓가락은 밴에서 챙긴 준비물로 회수한다.
- 금고 전면 경비가 남아 있어 점검 통로로 우회한다. 앙코르 종료와 장갑 회수 뒤 제한 시간이 시작된다.
- 바닥과 받침의 감지 장치를 먼저 보여주고 복제품 교환을 진행한다. 금고에 남긴 복제품을 별도 보석 인증 장치가 판별해 경보가 울린다.
- 탈출 연결대는 도입부에서 먼저 보여준다. 안전줄이 추락을 막고 원타치가 찬호를 끌어올린다.
- 사람을 다치게 하지 말라는 작전 기준을 직원 구조 장면으로 회수한다. 치킨 농담은 마지막 재합류 장면에서 회수한다.

## 그림 검수에서 발견하고 실제로 재생성한 오류

1. 배달 장면 식탁에 젓가락이 먼저 그려져 뒤 요청과 모순된 부분 제거.
2. 검색대 관객으로 다른 팀원들이 섞인 부분을 일반 관객으로 교체.
3. 계단에 무전 담당 락스가 실제 등장한 부분 제거.
4. 탈취 전 딱지 가슴에 보석 케이스가 그려진 부분 제거.
5. 장갑 회수 컷에서 가수가 다른 성별·복장으로 바뀐 부분을 도입부 가수로 수정.
6. 인증 빛이 진품 케이스를 비추던 부분을 금고 안 복제품 검사로 교체.
7. 앙코르 종료 뒤 무대 공연을 계속하는 가수 컷을 퇴장 음악 연주 밴드로 수정.
8. 옥상과 주차장 계단에 딱지·락스·뻐꾸기가 순간 이동한 부분 제거. 무전 말풍선만 남겼다.

## 공개 범위와 한계

이 공개본은 시퀀스 1~3의 정지 원본 웹툰이다. 움직임과 음성은 적용하지 않았다. M04 원작의 고해성사·현재 시점 반전은 유지 대상이며 이 뷰어에는 포함하지 않았다. 실제 독자 반응이나 네이버 순위로 검증한 상업 완성본이라고 주장하지 않는다. 세부 작화의 밀도, 안전 장비의 소부품, 보석 세팅의 작은 형태 차이는 후속 원화 정리에서 계속 다듬을 수 있다.

## 기술 검증

80개 컷의 원본 PNG 바이트를 유지하고 CSS 영역으로 분할했다. 20개 원화 각각의 3개 흰 구분선을 확인했다. 80개 접근성 설명과 장면 바로가기 링크를 포함한다. 공개 배포 뒤 실제 화면과 이미지 로딩 결과를 추가 기록한다.
