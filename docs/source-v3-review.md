# 원본 웹툰 개작 v3 · 자체 편집 검수

검수 대상: 새 원화 5개 스트립, 20컷. 검수 단계: 정지 원본. 무빙 제작과 외부 독자 테스트는 수행하지 않았다.

## 사용자 지적에 대한 실제 변경

| 지적 | 원본 변경 |
|---|---|
| 여러 손가락으로 지도를 긁음 | 지도와 긁는 동작 자체를 제거. 밴 안 대화와 실제 공간 컷으로 역할을 전달 |
| 금고 위치와 원형 지도 불일치 | 무대 → 앙코르 종료 → 지하 2층 금고 → 반출까지 4분이라는 시간 관계 명시 |
| 장갑의 가치가 추상적 | 희귀 천연 핑크 다이아, 감정가 100억 원으로 구체화 |
| 브리핑이 발표 화면처럼 보임 | 인물이 밴 안에서 장갑 사진 한 장을 건네며 이야기하는 장면으로 교체 |
| 손에서 붉은 선이 나옴 | 해당 효과와 동작 제거 |
| 영상 캡처와 설명 화면 삽입 | 기존 영상 프레임을 사용하지 않고 새 웹툰 원화를 제작 |
| 문받침의 목적이 불명확 | 자동 잠금 확인 → 동료에게 무전 → 작은 고무 문받침 → 열린 문 → 진입 → 회수·닫힘 순서 |
| 두 사람의 목적지가 불명확 | 골목 → 같은 후문 → 직원 통로 → B2 보관실 하행 계단으로 연결 |

## 실제 원화 검수와 수정 이력

- 1번 스트립: 금액·보석 설명과 반응 농담을 읽고, 사진 속 장갑과 확대 컷의 디자인을 확인했다.
- 2번 스트립: 무대 장면의 말풍선 꼬리가 가수를 가리키는 오류를 수정했다. 락스의 화면 밖 대사임을 명시했다. 4분의 기준을 ‘금고에 돌아온 뒤’로 수정했다. 배달 조끼를 뒤 스트립과 같은 검은색으로 맞췄다.
- 3번 스트립: 주문 확인, 휴게실 배달, 후문 발견을 같은 직원 통로로 연결했다. 휴게실 문, B2 표찰, 후문을 한 공간에 배치했다.
- 4번 스트립: 준비–행동–결과를 분리했다. 외부 문에 잘못 그려진 내부용 푸시바를 수정했다. 세로 여백과 글자 크기를 개선했다.
- 5번 스트립: 두 인물이 위로 향하는 것처럼 보이던 계단 컷을 위에서 내려다보는 하행 구도로 재제작했다. 발목 높이에 생성된 문 푸시바를 제거했다.

## 원본 평가

정보의 원인과 결과는 대사와 그림으로 연결된다. 표적 가격은 의뢰 보수와 혼동하지 않도록 감정가로 표현했다. 유머는 손 씻기, 고객의 치킨, 소스, 별점, 손/장갑의 말장난으로 배치했으며 본 임무의 긴장을 깨는 큰 개그 장면은 넣지 않았다.

기존 캐릭터 참조와 새 원화의 얼굴·헤어·체형·의상을 비교했다. 제작 도구의 성공 응답을 품질 통과로 간주하지 않고 공간과 말풍선 오류를 원화에서 반복 수정했다.

한계: 자체 편집 검수다. 독자의 재미·몰입을 외부 테스트로 입증한 상태는 아니다. 작품별 원화 서버의 접근 제한 때문에 대표 작품 전편에 대한 시각 분석을 마쳤다고 주장하지 않는다. 공개 원작자 강의에서 확인한 세로 여백, 가독성, 준비–행동–결과 원칙을 적용했다.

## 다음 제작 단계

이 원본의 원화와 말풍선을 기준으로 컷·인물·배경·소품을 분리한다. 움직임은 읽기를 방해하지 않는 범위에서 적용한다. 완성 무빙본의 기준은 ‘정지해도 읽히고, 움직이면 감정·긴장이 강화되는 웹툰’이다. 슬라이드 삽입이나 전체 그림 확대·이동만으로 무빙 제작 완료를 선언하지 않는다.
