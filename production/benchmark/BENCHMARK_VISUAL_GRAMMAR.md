# Visual Grammar

1. Every stable state must read as a finished commercial webtoon panel.
2. Establish geography before close detail: city → corridor → threat → exit → lock → target.
3. Use three depth bands only when they clarify space: foreground obstruction, character plane, environment.
4. Reserve extreme close-up for information change, not decoration.
5. Preserve readable faces, hands, footwear, handle and target object in the source art.
6. Keep navy/steel night values with warm skin and restrained red security accents.
7. Lettering participates in composition; it is never an app notification card.
8. Desktop uses a dark stage and an 820px maximum story canvas, not a stranded 480px strip.
